# COSYNE WEAR — Static Website

This is a minimal static website scaffold for the COSYNE WEAR brand. It includes simple pages and styling suitable for GitHub Pages or any static host.

Quick start

1. Open `index.html` in your browser or serve the folder with a static server.

2. To deploy on GitHub Pages, push this folder to a repository and enable Pages on the `main` branch.

Files

- `index.html` — Home
- `shop.html` — Product listing
- `product.html` — Product detail (prices shown in Ghana cedi, GH₵)
- `about.html` — About page
- `contact.html` — Contact form
- Contact details: cosynegroups@gmail.com, 0593108061, 0248696865
- `assets/css/style.css` — Styles
- `assets/js/main.js` — Minimal JS

Completed

- Real product images, award images, and videos are stored in `assets/images/`
- SEO descriptions and Open Graph metadata are included on every HTML page

Remaining setup

- Connect a payment provider such as Paystack or Shopify for automated checkout. The current MTN MoMo links open `*170#` and require customer confirmation.
- Add an analytics provider tracking ID, such as Google Analytics, before adding its tracking script.
